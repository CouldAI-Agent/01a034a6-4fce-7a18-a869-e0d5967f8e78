# طلحہ جے یو آئی لوگو

یہ ایک فلٹر (Flutter) ایپلی کیشن ہے جو جمعیت علمائے اسلام (JUI) کے روایتی سیاہ اور سفید دھاریوں والے جھنڈے کے پس منظر کے ساتھ "طلحہ" نام کا ایک خوبصورت اور پروفیشنل لوگو دکھاتی ہے۔

## خصوصیات
- جے یو آئی کے سیاہ اور سفید رنگوں کا استعمال
- دلکش گولڈ اور بلیک ڈیزائن کا امتزاج
- موبائل، ٹیبلیٹ اور ڈیسک ٹاپ پر بہترین ڈسپلے
- پروفیشنل اردو ٹائپوگرافی

## ٹیکنالوجی اسٹیک
- **فریم ورک:** Flutter
- **زبان:** Dart
- **پلیٹ فارمز:** Android, iOS, Web, Windows, macOS, Linux

## چلانے کا طریقہ
اس پراجیکٹ کو مقامی طور پر چلانے کے لیے درج ذیل کمانڈ استعمال کریں:

```bash
flutter run
```
